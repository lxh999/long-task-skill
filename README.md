# long-task-skill

让 AI 助手搞定长任务的通用技能：**任务拆解 · 断点续做 · 外挂记忆**。单文件、零依赖，适用于任何具备文件读写能力的 AI 助手。

## 这是什么

长任务（多步骤、跨多次对话的工程任务）最常见的失败方式：AI 干到一半"忘了"、上下文被压缩后跑偏、对话中断后从零再来。本技能用一个极简机制解决——**把任务状态写在磁盘上的计划文件里，而不是靠对话记忆**：

- 📋 **任务拆解**：接到 ≥3 步的任务，先写计划文件（需求 / 验收标准 / 步骤 checkbox / 状态与发现）
- 🔁 **断点续做**：进度每步回写文件。上下文被压缩、会话中断、甚至换一个 AI，读计划文件即可无损续作
- 🧠 **外挂记忆**：路径、方案决定、踩过的坑记进计划文件——丢了就要重来的信息绝不留在对话里

## 文件

- [`SKILL.md`](SKILL.md) —— 技能全文，这就是全部内容

## 安装到你的 AI 助手

**有技能机制的 AI**（Claude Code / WorkBuddy 等支持 SKILL.md 的产品）：把 `SKILL.md` 放进对应的技能目录即可。

**没有技能机制的 AI**：把 `SKILL.md` 全文贴进系统提示（System Prompt）或项目规则文件（`CLAUDE.md` / `.cursorrules` / `AGENTS.md` 等），同样生效。

**手动用法**：只把里面的「计划文件模板」发给 AI，并约定两条规则——"进度写进文件"、"续作先读文件"。

## 使用效果

对 AI 说：

> 帮我把这个项目从 xxx 迁移到 yyy，用 long-task 技能来做。

AI 会先创建 `.plans/<任务名>.md`，之后每完成一步都更新它。任何时候中断，只需说"继续"，AI 读了计划文件就能从断点接着干。
